# Project Statement

## Project Title
Grade Calculator

## Problem Statement
Calculating student marks and grades manually using CAT, TEE, internal marks, and attendance can take time and may cause calculation errors. This project provides a simple Python program to automate these calculations.

## Scope
The project calculates final marks and grades, checks attendance eligibility, and allows multiple students to be processed in one program run.

## Target Users
The main users are teachers or faculty members who need to calculate student results.

## High-Level Features
- Student and subject input
- CAT1, CAT2 and TEE marks calculation
- Attendance eligibility check
- Final marks calculation
- Grade calculation
- Multiple student processing
