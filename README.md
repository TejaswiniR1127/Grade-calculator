# Project

## Project Description

Project is a simple Python-based Grade Calculator designed to help teachers calculate the marks and grades of students.

The program takes student details, CAT1, CAT2, TEE, internal marks, attendance, class average, and standard deviation as input. It then calculates the final marks and grade.

The project is made using three Python modules to keep the code simple and organized.

## Features

- Enter student name and subject
- Enter CAT1, CAT2, TEE, and internal marks
- Check attendance eligibility
- Calculate final marks out of 100
- Calculate the student's grade
- Use class average and standard deviation for grading
- Process multiple students in one program run

## Purpose of the Three Modules

### 1. Main Python File

The main file controls the complete program.

It:
- Takes input from the teacher
- Calls the required functions
- Calculates the final marks
- Displays the result
- Allows multiple students to be entered

### 2. `marks_calculation.py`

This module is used for marks-related calculations.

It:
- Converts CAT marks
- Calculates the student's grade
- Uses total marks, class average, and standard deviation

### 3. `helper_module.py`

This module is used for attendance checking.

It:
- Checks whether the student is eligible based on attendance
- Gives attendance marks when the student is eligible

## Technologies Used

- Python 3
- Python functions
- Python modules
- Conditional statements
- Loops
- Lists
- User input
